# REX ICON 图标库

一套专为 Emby 设计的圆角图标库，共 **481 个图标**，分为「珠光版」「透明版」「透明·纯白版」三种风格，覆盖 REX 品牌色系、AVDB、主流影音平台与卡通角色。

---

## ✨ 特点

- 🎨 **三版本**：珠光版（209 个）带珍珠底面；透明版（232 个）纯透明底；纯白版（40 个）白色单色透明底，适合深色主题
- 🌏 **中文命名**：文件夹与图标名称均为中文，一眼看懂
- 📐 **规格统一**：1:1 正方形，适合作为媒体库图标
- 🗂 **结构清晰**：按「版本 → 分类」两层组织

## 🚀 使用方法

### Emby 图标库导入

```
https://rexicon.speedo.de5.net/rexicon.json
```

备用源站地址：

```
https://raw.githubusercontent.com/speedoa/rexicon/main/rexicon.json
```

### 单个图标引用

```
https://raw.githubusercontent.com/speedoa/rexicon/main/icon/珠光版/REX/兰花紫.png
```

> 中文路径的实际请求需 URL 编码，`rexicon.json` 内的链接已自动编码，可直接使用。
