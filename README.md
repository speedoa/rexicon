# REX ICON 图标库

一套专为 Emby 设计的珠光背景圆角图标库，共 **127 个精美图标**，涵盖色彩系列、平台品牌、卡通角色、AVDB 专属系列等多个分类。

---

## ✨ 图标特点

- 🎨 **珠光质感**：统一的珠光背景圆角设计，视觉风格统一
- 🌏 **中文命名**：全部图标使用中文名称，一目了然
- 📁 **分类整理**：16 个分类文件夹，结构清晰
- 🖼️ **高清规格**：640×640 / 1024×1024 分辨率，适配各类场景

## 🚀 使用方法

### Emby 图标库导入
在 Emby 图标库设置中，填入以下地址：
```
https://rexicon.speedo.de5.net/rexicon.json
```

### 直接引用单个图标
```
https://raw.githubusercontent.com/speedoa/rexicon/main/icon/01-rex-colors/rex-square-01-ocean-blue-rounded.png
```
